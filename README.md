# RLOOP — Robot Arena

Two-robot arena with PvP, PvC, CvC; headless C++ gameplay core, Python DQN training, and Unreal Engine 5 presentation.

## Development stage

The first vertical slice is a headless deterministic world simulation, kinematic chained box pushing, combat resolution, debug PvP viewer and regression/replay tests. Character balance numbers remain configurable and are not finalized.

The repository currently contains specifications and collaboration documents only; no code has been added yet.
